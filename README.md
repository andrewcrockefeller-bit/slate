# Slate

An infinite handwriting canvas with an AI tutor that watches you work and places
hints beside your problem — never the answer.

Milestone: **M4 — provider seam, code-complete, not yet wired to the UI.**
See `docs/status/current.md` for exactly what that means.

## Layout

```
Packages/SlateCore/       Layer 1 — domain core. Foundation only. Builds on Linux.
Packages/SlatePlatform/   Layer 2 — platform adapters. Apple frameworks live here.
App/Slate/                Layer 3 — SwiftUI. Zero business logic.
Tools/                    check-layer-purity.sh, setup-mac.sh, push helpers.
CLAUDE.md                 Standing engineering rules — read this first if you're
                           an AI assistant working in this repo.
docs/decisions.md         Why things are the way they are. The canonical log —
                           append to this one, not a docs/decisions/ directory.
docs/brief/                The founding brief, the v1.5 addendum, and the
                           prototype origin story — what this app is and why.
docs/status/current.md    Where the build actually stands, milestone by
                           milestone, including what's built but unverified.
M0-xcode-setup.txt        First-time Xcode project setup and signing runbook.
M1-test-plan.txt          The M1 (ink capture) test procedure and feel checklist.
```

## The rule everything else depends on

`SlateCore` imports Foundation and nothing else, has no package dependencies, and
compiles and passes its tests on Linux. That single property is what makes the
Android and Windows ports a port rather than a rewrite. It is enforced by CI on
every push, and by `Tools/check-layer-purity.sh` before the build so that a
violation is reported as a violation instead of as a compile error.

If you need a platform capability in the domain core, declare a protocol in
`SlateCore` and implement it in `SlatePlatform`. Do not relax the check.

## Running things

```bash
# Everything: toolchain check, purity guard, both test suites, XcodeGen
./Tools/setup-mac.sh

# Layer 1 only, the part that must stay portable
swift test --package-path Packages/SlateCore

# Layer 2 only (Apple platforms only)
swift test --package-path Packages/SlatePlatform

# The invariant guard on its own
./Tools/check-layer-purity.sh
```

The iPad app is built from Xcode, generated by XcodeGen from `project.yml` (not
committed — run `setup-mac.sh` or `xcodegen generate` after cloning). See
`M0-xcode-setup.txt` for first-time signing setup.

## Where the design lives

The founding brief, the v1.5 addendum, and the prototype origin story are in
`docs/brief/` in this repo, and are also kept in a claude.ai Project ("AI Live
tutoring") for planning conversations outside the terminal — the two copies
are synced by hand, so treat this repo's copy as canonical if they ever
disagree. Section 10 of the founding brief lists the six model decisions v1
has to make correctly so that v1.5 is not a migration.
